# Internet State Detector

**Текущая версия:** `0.3.7`

Интеграция для Home Assistant, которая определяет состояние подключения к Интернету на основе доступности наборов URL-адресов.

Это позволяет создать сенсор с одним из четырех состояний:
- `Full access` (Полный доступ)
- `Russia only` (Доступ только к сайтам РФ)
- `Whitelist only` (Доступ только по белому списку)
- `No internet` (Нет интернета)

## Установка

Рекомендуемый способ установки - через [HACS (Home Assistant Community Store)](https://hacs.xyz/).

1. Добавьте этот репозиторий в HACS как "пользовательский репозиторий" (`Custom repository`).
2. Выберите категорию `Интеграция`.
3. Найдите "Internet State Detector" в списке и нажмите "Скачать".
4. Перезапустите Home Assistant.

## Настройка

1. Перейдите в `Настройки` -> `Устройства и службы` -> `+ Добавить интеграцию`.
2. Найдите `Internet State Detector`.
3. В окне настройки укажите три списка URL-адресов для проверки:
    - **Глобальные сайты**
    - **Российские сайты**
    - **Белый список**

Интеграция создаст сенсор `sensor.internet_state`, который будет отражать текущий статус подключения.

## Изменение списков URL

После установки вы можете изменить списки URL в любой момент:
1. Перейдите в `Настройки` -> `Устройства и службы`.
2. Найдите интеграцию `Internet State Detector` и нажмите `Настроить`.
3. В открывшемся окне вы сможете отредактировать все три списка URL.
